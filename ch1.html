Ch1. Introduction — 자료구조란?

1. Why Data Structure(자료구조)?

핵심 이론 & 배경

  • 핵심 등식: Program = Data Structure + Algorithm
  • Data Structure: 정보(data)를 어떻게 조직(organize) 하는가
  • Algorithm(알고리즘): 프로그램이 task를 어떻게 수행하는가
  • Why 배워야 하는가?: 오픈소스/AI 코딩 툴이 넘쳐도, 내 문제는 기존 해답과 정확히 일치하지 않는다 → 자료구조를 정의/이해/수정/구현할 수 있어야 adjust 가능.

직관 & 예시

  • AI 모델은 특정 data structure에 특화됨:
Data structure Related AI model
Grid(격자) CNN
Sequence(시퀀스) Transformer/RNN/LSTM/GRU
Set(집합) Deep Sets
Tree(트리) TreeLSTM
Point PointNet
Graph(그래프) GNN
  • → 문제의 데이터 형태를 먼저 파악해야 올바른 모델/알고리즘 선택 가능.

2. Course Roadmap (학습 지도)

전체 목차

  1. C++ — 실습 기반
  2. Algorithm Analysis — 하드웨어 독립적 비교 (Big-O)
  3. List(리스트) / Stack(스택) / Queue(큐) — 선형 자료구조
  4. Tree — 계층 구조
  5. Priority Queue(우선순위 큐) / Heap(힙) — 우선순위 기반
  6. Sorting(정렬) — 정렬
  7. Special Trees(트리) — BST, AVL, …
  8. Graph — 비계층, 임의 연결
  9. Shortest Path(최단 경로) / MST
  10. String — Trie(트라이), suffix tree, pattern matching

각 주제의 motivational question

  • Algorithm: "어느 알고리즘이 사용 컴퓨터 사양과 무관하게 더 나은가?"
  • List/Stack/Queue: 이름 그대로 동작
  • Tree: 가족/학술 tree 같은 계층 표현
  • Priority Queue: 현실의 우선순위 반영
  • Sorting: 계산적으로 순서를 만드는 법
  • Graph: 계층 없이 anything-to-anything 연결
  • Shortest Path(경로): A→B 가장 빠른 경로
  • MST: 모든 지점을 최소 비용으로 연결
  • String: Trie, suffix tree, 패턴 매칭
