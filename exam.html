1. 개념 치트

Circular Queue(원형 큐) — modulo와 Full/Empty 구분

일반 배열 큐는 Dequeue/Enqueue를 반복하면 Front/Rear가 오른쪽으로만 밀려, 앞이 비어도 Rear가 끝에 닿으면 삽입 불가. 배열의 끝과 처음을 논리적으로 연결해 해결한다.

  • 인덱스 갱신: Rear = (Rear + 1) % size, Front = (Front + 1) % size

Empty와 Full이 둘 다 Front == Rear

해결책 둘 중 하나를 쓴다:

  • 1칸 비워두기(가장 흔함): (Rear + 1) % size == Front이면 Full로 간주.
  • count 변수로 데이터 개수를 별도 추적.
Tree 재구성(Reconstruction) — 어떤 순회 조합이 가능한가

단일 순회 하나만으로는 원본 트리를 복원할 수 없다. Inorder를 포함한 조합이면 가능 — Inorder가 왼쪽/오른쪽 구간의 경계를 알려주기 때문.

  • ✓ Preorder + Inorder · ✓ Postorder + Inorder · ✓ Level-order + Inorder
  • ✗ Preorder + Postorder

AVL Tree — bf · 회전 4유형 · Insert vs Delete
  • AVL = BST + Height-Balanced: 모든 노드 . bf(x) = h(왼쪽) − h(오른쪽).
  • LL → 우회전 · RR → 좌회전 · LR → 자식 좌회전 + 부모 우회전 · RL → 자식 우회전 + 부모 좌회전.
  • 회전 후에도 BST 성질(inorder 순서) 유지.
  • Insert는 최대 1회 회전, Delete는 연쇄 회전 가능(회전으로 높이가 줄면 위로 전파).

3. Pseudocode 모음

Array List — insert / erase 
METHOD insert(index, element) {
    IF index < 0 OR index > size THEN THROW OutOfBoundsException
    IF size == capacity THEN resize(capacity * 2)

    // 데이터를 한 칸씩 뒤로 밀기 (Right Shift)
    FOR i FROM size DOWNTO index + 1 DO
        data[i] ← data[i - 1]
    data[index] ← element
    size ← size + 1
}

METHOD erase(index) {
    IF index < 0 OR index >= size THEN THROW OutOfBoundsException
    removedValue ← data[index]

    // 데이터를 한 칸씩 앞으로 당기기 (Left Shift)
    FOR i FROM index TO size - 2 DO
        data[i] ← data[i + 1]
    size ← size - 1
    RETURN removedValue
}
Linked List (dummy head) — insert / removeAt

왜 dummy?

맨 앞 삽입·삭제도 예외 없이 같은 코드로 처리하려고, 데이터를 담지 않는 빈 head 노드를 둔다. prev는 항상 존재한다.

CONSTRUCTOR() {
    head ← NEW Node()      // 더미 노드
    head->next ← NULL
    size ← 0
}

METHOD insert(index, value) {
    IF index < 0 OR index > size THEN RETURN ERROR
    prev ← head
    FOR i FROM 0 TO index - 1 DO prev ← prev->next   // 삽입 위치 바로 앞

    newNode ← NEW Node()
    newNode->data ← value
    newNode->next ← prev->next
    prev->next ← newNode
    size ← size + 1
}

METHOD removeAt(index) {
    IF index < 0 OR index >= size THEN RETURN ERROR
    prev ← head
    FOR i FROM 0 TO index - 1 DO prev ← prev->next

    target ← prev->next
    prev->next ← target->next
    DELETE target
    size ← size - 1
}
Stack — Array / Linked 
// Array Stack: top = 가장 위 원소의 인덱스 (비면 -1)
METHOD push(stack, value) {
    IF stack.top == MAX_SIZE - 1 THEN SIGNAL "Stack Overflow"
    stack.top ← stack.top + 1
    stack.data[stack.top] ← value
}
METHOD pop(stack) {
    IF stack.top == -1 THEN SIGNAL "Stack Underflow"
    value ← stack.data[stack.top]
    stack.top ← stack.top - 1
    RETURN value
}
// Linked Stack: top이 첫 노드를 가리킴
METHOD push(value) {
    newNode ← NEW Node()
    newNode->data ← value
    newNode->next ← top     // 기존 top을 아래로
    top ← newNode
    size ← size + 1
}
METHOD pop() {
    IF top == NULL THEN SIGNAL "Stack Underflow"
    temp ← top
    value ← temp->data
    top ← top->next
    DELETE temp             // C++에서 메모리 해제 필수
    size ← size - 1
    RETURN value
}
Queue — Circular(Array) / Linked 
// Circular Queue: front는 첫 요소의 "한 칸 앞", 1칸 비워두기 방식
METHOD enqueue(queue, value) {
    IF (queue.rear + 1) % queue.capacity == queue.front THEN
        SIGNAL "Queue Overflow"
    queue.rear ← (queue.rear + 1) % queue.capacity
    queue.data[queue.rear] ← value
}
METHOD dequeue(queue) {
    IF queue.front == queue.rear THEN SIGNAL "Queue Underflow"
    queue.front ← (queue.front + 1) % queue.capacity
    RETURN queue.data[queue.front]
}
// Linked Queue: front(나가는 쪽), rear(들어오는 쪽)
METHOD enqueue(value) {
    newNode ← NEW Node()
    newNode->data ← value
    newNode->next ← NULL
    IF rear == NULL THEN front ← newNode; rear ← newNode   // 빈 큐
    ELSE rear->next ← newNode; rear ← newNode
    size ← size + 1
}
METHOD dequeue() {
    IF front == NULL THEN SIGNAL "Queue Underflow"
    temp ← front
    value ← temp->data
    front ← front->next
    IF front == NULL THEN rear ← NULL    // 비게 된 경우 rear도 정리
    DELETE temp
    size ← size - 1
    RETURN value
}

Linked Queue의 dequeue에서 마지막 노드를 빼면 rear도 NULL로 갱신해야 한다. 안 하면 rear가 해제된 노드를 가리킨다.

// Linked tree 순회 (재귀)
METHOD preOrder(node) {
    IF node == NULL THEN RETURN
    PRINT node->data                   // 1. 현재
    preOrder(node->left)               // 2. 왼쪽
    preOrder(node->right)              // 3. 오른쪽
}
METHOD inOrder(node) {
    IF node == NULL THEN RETURN
    inOrder(node->left)
    PRINT node->data
    inOrder(node->right)
}
// DFS — 재귀 없이 스택으로
METHOD DFS_Stack(startNode) {
    IF startNode == NULL THEN RETURN
    Stack s
    s.push(startNode)
    WHILE s is not empty DO
        curr ← s.pop()
        PRINT curr->data
        // 오른쪽을 먼저 넣어야 왼쪽이 먼저 나온다 (LIFO)
        IF curr->right != NULL THEN s.push(curr->right)
        IF curr->left  != NULL THEN s.push(curr->left)
    END WHILE
}

// BFS — 큐
METHOD BFS(root) {
    IF root == NULL THEN RETURN
    Queue q
    q.enqueue(root)
    WHILE q is not empty DO
        curr ← q.dequeue()
        PRINT curr->data
        IF curr->left  != NULL THEN q.enqueue(curr->left)
        IF curr->right != NULL THEN q.enqueue(curr->right)
    END WHILE
}

DFS = Stack(또는 재귀 호출 스택), BFS = Queue. preOrder/inOrder가 곧 DFS의 한 형태다.

Heap — push / pop (array, Max-Heap) 
METHOD push(heap, value) {
    heap.size ← heap.size + 1
    curr ← heap.size
    heap.data[curr] ← value
    // 부모보다 크면 위로 교체 (Up-heap)
    WHILE curr > 1 AND heap.data[curr/2] < heap.data[curr] DO
        swap(heap.data[curr/2], heap.data[curr])
        curr ← curr / 2
    END WHILE
}

METHOD pop(heap) {
    IF heap.size == 0 THEN RETURN ERROR
    maxValue ← heap.data[1]
    heap.data[1] ← heap.data[heap.size]   // 마지막을 루트로
    heap.size ← heap.size - 1

    curr ← 1
    WHILE (curr * 2) <= heap.size DO
        child ← curr * 2
        // 더 큰 자식 선택
        IF child + 1 <= heap.size AND heap.data[child] < heap.data[child+1] THEN
            child ← child + 1
        IF heap.data[curr] >= heap.data[child] THEN BREAK
        swap(heap.data[curr], heap.data[child])
        curr ← child
    END WHILE
    RETURN maxValue
}
Sort — Merge / Quick / Quick(in-place) 
Merge-sort(L, n):
    if n == 1: return L                    // 기저 조건
    L1 = L의 앞 절반, L2 = L의 뒤 절반        // 분할
    return merge(Merge-sort(L1, n/2), Merge-sort(L2, n/2))
Quicksort(A):
    if length(A) <= 1 then return A
    pivot 선택 후 A에서 제거
    for each x in A:
        if x < pivot then append x to L
        else append x to R
    return concatenate(Quicksort(L), pivot, Quicksort(R))
Quicksort(A, low, high):
    if low < high:
        p = Partition(A, low, high)
        Quicksort(A, low, p - 1)      // pivot은 확정 — 범위에서 제외
        Quicksort(A, p + 1, high)

Partition(A, low, high):
    pivot = A[low]
    leftwall = low                     // pivot 미만 구역의 끝
    for i = low + 1 to high:
        if A[i] < pivot:
            leftwall = leftwall + 1    // 구역 확장 뒤 교환
            swap(A[i], A[leftwall])
    swap(A[low], A[leftwall])          // pivot을 경계로
    return leftwall
BST — search / insert / delete (CLRS 스타일) 
search(x, k):
    if x == NIL or k == x.key: return x
    if k < x.key: return search(x.left, k)
    else:         return search(x.right, k)
insert(T, z):
    y = NIL; x = T.root
    while x != NIL:              // 삽입 위치의 부모 y 찾기
        y = x
        if z.key < x.key: x = x.left
        else:             x = x.right
    z.parent = y
    if y == NIL:        T.root = z    // 빈 트리
    elif z.key < y.key: y.left = z
    else:                y.right = z
delete(T, z):
    if z.left == NIL:                    // 자식 0개 또는 오른쪽만
        transplant(T, z, z.right)
    else if z.right == NIL:              // 왼쪽만
        transplant(T, z, z.left)
    else:                                // 자식 둘
        y = minimum(z.right)             // Successor
        if y.parent != z:
            transplant(T, y, y.right)
            y.right = z.right
            y.right.parent = y
        transplant(T, z, y)
        y.left = z.left
        y.left.parent = y

transplant(T, u, v)는 u의 자리를 서브트리 v로 통째로 교체하는 도우미. Degree-2 삭제에서 successor y가 z의 직계 자식이 아니면, y를 먼저 빼내고(①/② 환원) z 자리에 심는 두 단계로 나뉜다.

General Tree → LCRS 변환 코드 
STRUCT BinaryNode {
    INT data;
    BinaryNode* left;   // 원래의 첫째 자식
    BinaryNode* right;  // 원래의 다음 형제
}

METHOD convertToBinary(gNode) {
    IF gNode == NULL THEN RETURN NULL
    bNode ← NEW BinaryNode(gNode->data)

    IF gNode.children.isNotEmpty() THEN
        bNode->left ← convertToBinary(gNode.children[0])   // 첫째 자식

    // 나머지 자식들을 형제 체인으로 연결
    curr ← bNode->left
    FOR i FROM 1 TO gNode.children.size() - 1 DO
        curr->right ← convertToBinary(gNode.children[i])
        curr ← curr->right
    RETURN bNode
}
