Ch9. Binary Search Tree

1. BST(이진 탐색 트리) 정의

핵심 Property

  • Binary Tree이면서 각 노드가 (key, value) 쌍 저장, key는 unique
  • BST property (핵심):
    • 모든 노드 에 대해:
      • n.key > left subtree 모든 key
      • n.key < right subtree 모든 key
    • → 재귀적으로 모든 subtree가 BST여야 함
  • 별칭: ordered/sorted binary tree

왜 쓰나?

  • Search, Insert, Delete 모두 평균
  • 동시에 Sorted order output (inorder 순회)도
  • → Dynamic dictionary의 기본형. Hash table과 달리 순서 유지.

2. Search

알고리즘

Search(x, T):
    if T == NULL: return NOT_FOUND
    if x == T.key: return T
    if x <  T.key: return Search(x, T.left)
    else:          return Search(x, T.right)
  • 매 step에서 한쪽 subtree 버림 → 높이만큼만 탐색

시간복잡도

  • Balanced BST:
  • Skewed (linked list처럼 한쪽으로 치우침): ← worst case
  • → 균형 유지가 핵심 과제 (Ch10 AVL에서 해결)

3. Inorder(중위 순회) Traversal(순회) = Sorted Output

핵심 사실

  • BST의 inorder traversal = key를 오름차순으로 반환

증명 직관

  • Inorder 정의: left → node → right
  • BST property: left의 모든 key < node < right의 모든 key
  • → 재귀적으로 inorder는 '작은 것부터 큰 것까지' 순서대로 출력

5. Delete — 3 Cases

핵심 아이디어

  • 삭제할 노드의 자식 수에 따라 케이스 분리
  • 목표: BST property 유지하면서 제거

Case 1 — Leaf node (degree 0)

  • 그냥 제거. 부모의 해당 child pointer를 NULL로.

Case 2 — Degree 1 node

  • 유일한 자식이 그 자리를 대체 (부모와 직접 연결)

Case 3 — Degree 2 node (어려운 케이스)

방법: 삭제 노드를 in-order successor (또는 predecessor)로 값 교체 후, 그 successor 노드를 실제 삭제.
  • In-order successor = right subtree의 최솟값 = right subtree에서 계속 왼쪽으로
  • In-order predecessor = left subtree의 최댓값 = left subtree에서 계속 오른쪽으로

중요: successor 노드는 반드시 degree ≤ 1

  • Why?: '최솟값'이면 left child가 없음 (있다면 그 left child가 더 작을 것)
  • → successor는 최대 right child 1개만 → Case 1 or Case 2로 환원
  • 따라서 재귀적으로 또 degree 2를 만날 일 없음 → successor 삭제는 상수 작업

8. BST 사용처 & 한계

BST가 적합한 경우

동적 집합에 대해 Insert, Search, Delete, Range scan (sorted order 출력) 모두 지원해야 할 때.
  • Priority Queue(heap)과 차이:
    • Heap(힙): Min(또는 Max) 빠름, 전체 sorted 출력 불가
    • BST: 모든 key에 대한 search/update 가능, sorted output 가능
  • Hash table과 차이:
    • Hash: avg search/insert, 순서 없음
    • BST: 순서 보존, range query 가능

한계: Unbalanced 문제

  • 삽입 순서에 따라 skewed → worst
  • 해결: self-balancing BST (Ch10 AVL)
