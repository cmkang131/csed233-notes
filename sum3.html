1. 알고리즘과 성능

알고리즘(Algorithm): 문제를 유한한 시간 내에 해결하기 위한 단계별 절차.

예: 1부터 100까지의 합 — 입력 100 → 절차: sum에 1..100을 더함 → 출력 5050.

1.1 좋은 알고리즘의 5가지 조건

  1. 입력(Input)이 명확한가 — 배열, 정수, 문자열 등.
  2. 출력(Output)이 명확한가 — 정렬된 배열, 최댓값, true/false 등.
  3. 명확성(Definiteness) — "비슷한 것"이 아니라 "정확히 이것".
  4. 유한성(Finiteness) — 무한 루프 없음. while(true) ✗, while(n--) ✓.
  5. 효율성(Effectiveness) — 컴퓨터로 실제 실행 가능한 단계.

1.2 성능은 두 축으로 측정한다

  • Time complexity(시간복잡도) : 입력 크기 n에 따라 몇 번의 연산? 예: 선형 탐색은 n번 비교 → .
  • Space complexity(공간복잡도) : 입력 크기 n에 따라 얼마의 메모리? 예: 32비트 정수 배열은 4n bytes → .
  • 실무 우선순위: ① 시간(사용자가 기다린다) ② 공간(메모리가 충분하면 덜 중요).

4. 점근 표기법 3종

Big-O — 상한 ("최대 이 정도")

  • 알고리즘이 아무리 느려도 c·f(n)을 넘지 않는다는 위쪽 경계.

Big-Ω — 하한 ("최소 이 정도")

  • 예: 배열을 전부 봐야 하는 작업은 최소 .

Big-Θ — 동등 ("정확히 이 정도")

  • 예: Merge Sort는 최악·평균 모두 .

예제 · Big-O 증명 연습

T(n) = 2n + 3 이 O(n)임을 보이려면 2n + 3 ≤ c·n을 만족하는 상수 c를 찾으면 된다.

c = 3으로 잡으면 n ≥ 3에서 성립 → O(n) ✓. 같은 식으로 3n² + 5n + 7 = O(n²), 5 = O(1), 2ⁿ = O(2ⁿ).

배열 [3, 1, 4, 1, 5, 9, 2, 6]에서 선형 탐색을 예로 들면:

실무에서는 이렇게 고른다

  • 최악이 중요 — 실시간 시스템(의료, 항공), 금융 거래 → Merge Sort O(n log n) 보장.
  • 평균이 중요 — 일반 데이터 처리, 온라인 게임 → Quick Sort 평균 O(n log n).
  • 최선이 중요 — 거의 정렬된 데이터 → Insertion Sort 최선 O(n).

6. Quiz

Q1O(n²)과 O(n)의 차이를 n = 1,000,000일 때 비교하라.
힌트

n² = n × n. n에 10⁶을 각각 대입해 보자.

정답

개념은 힌트 참고.

  1. O(n): 10⁶ = 100만 회 연산.
  2. O(n²): (10⁶)² = 10¹² = 1조 회 연산.
  3. 비율: 10¹² / 10⁶ = 10⁶.
정답: 100만 회 vs 1조 회 — 100만 배 차이.
Q2O(n log n)은 어떤 의미인가?
힌트

n × log₂(n). log₂(10⁶) ≈ 20임을 이용해 O(n²)과 비교해 보자.

정답

개념은 힌트 참고.

  1. n = 10⁶이면 log₂(n) ≈ 20.
  2. n log₂(n) ≈ 10⁶ × 20 = 2천만 회.
  3. O(n²) = 1조 회와 비교하면 약 50,000배 빠름.
정답: 입력 n에 대해 대략 n × log₂(n)번의 연산. n = 100만이면 약 2천만 회로, O(n²)보다 약 5만 배 빠르다.
Q3왜 최악의 경우(Worst Case)를 기준으로 분석하는가?
힌트

"보장"의 관점에서 생각해 보자. 평균은 입력 분포에 따라 달라지지만 최악은 어떤 입력이 와도 성립한다.

정답

개념은 힌트 참고.

  1. 평균 분석은 입력 분포 가정이 필요하고, 가정이 틀리면 무너진다.
  2. 최악 분석은 어떤 입력이든 "이 이상은 안 걸린다"를 보장한다.
  3. 실시간·금융처럼 지연이 곧 사고인 시스템에서는 이 보장이 필수다.
정답: 최악의 경우 분석은 성능을 "보장"하기 때문 — 어떤 입력이 와도 걸리는 시간의 상한을 약속할 수 있다.
Q4Bubble Sort O(n²)와 Merge Sort O(n log n)에서 n = 1,000일 때 차이는?
힌트

log₂(1000) ≈ 10. 각각 대입해 보자.

정답

개념은 힌트 참고.

  1. Bubble Sort: n² = 1000² = 100만 회.
  2. Merge Sort: n log₂ n ≈ 1000 × 10 = 1만 회.
  3. 비율: 100만 / 1만 = 100배.
정답: 100만 회 vs 약 1만 회 — 100배 차이.
Q5경험적 분석과 이론적 분석의 차이는?
힌트

측정이냐 계산이냐, 그리고 환경에 의존하느냐가 쟁점.

정답

개념은 힌트 참고.

  1. 경험적: 실제로 구현해 실행 시간을 측정 → 현실적이지만 환경(CPU/OS)에 따라 달라진다.
  2. 이론적: 수학적으로 연산 횟수를 계산 → 환경 독립적이고 일반화되지만 상수는 무시한다.
정답: 경험적 = 구현 후 측정(환경 의존), 이론적 = 수학적 계산(환경 독립, 일반적).
