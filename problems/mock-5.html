개념 정리 · 큐의 상태와 위상 순서
  • 큐에 두 정점 이상이 동시에 존재하면, 현재 남아 있는 그래프에서 그 정점들은 모두 진입차수가 0이므로 서로 다른 순서로 처리할 수 있다. 따라서 가능한 위상 순서가 둘 이상 존재한다. 단, FIFO 큐에서는 dequeue 순서가 큐의 저장 순서에 따라 정해지므로, 서로 다른 실행은 enqueue 순서를 다르게 하는 것으로 이해한다.
  • 유일성을 보려면 각 단계의 큐 상태를 적어 본다. 큐 크기가 항상 1 이하여야 유일하다.

강의 슬라이드 Ch14 · in-degree 큐 알고리즘 (Quiz 14-2)

풀이
  • (1) 위상 정렬 알고리즘에서 큐에 두 정점 이상이 동시에 존재한다면, 이 정점들은 현재 남아 있는 그래프에서 진입차수가 모두 0이므로 서로 간에 선후 제약이 없다. 따라서 이들의 처리 순서를 달리하여 서로 다른 유효한 위상 순서를 만들 수 있으므로 위상 정렬은 유일하지 않다. FIFO 큐 구현에서는 이 차이가 진입차수 0 정점들의 enqueue 순서에 따라 나타날 수 있다. 큐 안의 정점들은 서로 선후 관계가 없어(in-degree 0) 어떤 순서로 내보내도 위상 조건을 만족한다.
  • (2) 초기 진입차수는 A=0, B=1, C=1, D=2, E=1이다. A를 먼저 처리하고 B, C 순서로 enqueue할 경우, 각 dequeue 이후의 큐 상태는 [A] → A 처리 후 [B,C] → B 처리 후 [C] → C 처리 후 [D] → D 처리 후 [E] → E 처리 후 []이다. A를 처리한 직후 B와 C가 동시에 진입차수 0이 되므로 위상 순서는 유일하지 않다. 실제로 A,B,C,D,E와 A,C,B,D,E가 모두 유효한 위상 순서다.
  • (3) 간선 B → C를 추가한다(C의 in-degree가 2로). 큐 추적: [A] → [B] → B 제거(C의 in-degree 0) → [C] → C 제거(D의 in-degree 0) → [D] → [E]. 모든 단계에서 큐에 최대 1개뿐이라 선택의 여지가 없고 위상 순서는 A, B, C, D, E로 유일하다.
최종 답(2) 유일하지 않다. 큐에 B, C 동시 존재   (3) B → C 추가 → A,B,C,D,E로 유일
