  • 큐에 2개 이상이 있으면 어느 것을 먼저 꺼내도 알고리즘은 진행된다. 선택지가 곧 서로 다른 출력 순서다.
  • 유일성을 보려면 각 단계의 큐 상태를 적어 본다. 큐 크기가 항상 1 이하여야 유일하다.

강의 슬라이드 Ch14 · in-degree 큐 알고리즘 (Quiz 14-2)

풀이
  • (1) 큐에 두 개 이상 있으면 어느 것을 먼저 dequeue하느냐에 따라 출력 순서가 달라지므로, 서로 다른 유효한 위상 순서가 2개 이상 존재한다. 큐 안의 정점들은 서로 선후 관계가 없어(in-degree 0) 어떤 순서로 내보내도 위상 조건을 만족한다.
  • (2) in-degree: A=0, B=1, C=1, D=2, E=1. 큐 추적: [A] → A 제거 → [B, C]: 두 개! → 이후 진행. B와 C가 동시에 큐에 있으므로 순서가 유일하지 않다. 실제로 A,B,C,D,E와 A,C,B,D,E가 모두 유효하다.
  • (3) 간선 B → C를 추가한다(C의 in-degree가 2로). 큐 추적: [A] → [B] → B 제거(C의 in-degree 0) → [C] → C 제거(D의 in-degree 0) → [D] → [E]. 모든 단계에서 큐에 최대 1개뿐이라 선택의 여지가 없고 위상 순서는 A, B, C, D, E로 유일하다.
최종 답(2) 유일하지 않다. 큐에 B, C 동시 존재   (3) B → C 추가 → A,B,C,D,E로 유일
