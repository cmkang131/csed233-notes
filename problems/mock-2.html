  • (a) 모든 내부 노드가 자식 2개면 레벨 는 개의 leaf → (완전 이진 모양). 모든 내부 노드가 자식 3개면 (완전 삼진 모양). 자식 수의 하한/상한이 그대로 leaf 수의 하한/상한이 된다.
  • (b) 의 양변에 로그를 취하면 . 2ʰ ≤ L ≤ 3ʰ의 양변에 로그를 취하면 log₃ L ≤ h ≤ log₂ L이므로 h = Θ(log L)이다. 또한 2-3 트리에서는 모든 내부 노드가 적어도 2개의 자식을 가지므로 내부 노드 수 I는 I ≤ L − 1이고, 전체 노드 수 n = I + L에 대해 L ≤ n ≤ 2L − 1이 성립한다. 따라서 n = Θ(L)이므로 최종적으로 h = Θ(log L) = Θ(log n)이다.
  • (c) 모든 leaf가 같은 레벨이라는 불변식이 을 강제한다. BST는 이런 불변식이 없어 높이 의 경로로 퇴화할 수 있다.
