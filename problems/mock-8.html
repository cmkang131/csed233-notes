개념 정리 · Naive의 최악 조건과 KMP의 실패 함수
  • Naive 최악: 모든 시작 위치에서 거의 끝까지 일치하다 마지막 문자에서 실패하는 경우. 시작 위치는 개.
  • KMP: 불일치 시 패턴 인덱스 j > 0이면 실패 함수를 이용해 j를 감소시키고 같은 텍스트 문자를 다시 비교한다. j = 0이면 텍스트 인덱스를 한 칸 전진시킨다. 어느 경우에도 텍스트 인덱스는 후진하지 않는다.

풀이
  • (a) (a 8개), . 매 위치에서 a, a까지 맞고 마지막 b에서 실패해 위치당 최대 비교가 나온다.
  • (b) 가능한 시작 위치는 0부터 5까지 총 6곳이다. 각 위치에서 처음 두 문자는 일치하고 세 번째 문자에서 실패하므로 위치당 3회 비교한다. 따라서 총 비교 횟수는 6 × 3 = 18회이다. 일반적으로 1 ≤ m ≤ n일 때 Naive의 최악 비교 횟수는 (n−m+1)m회이며, 이는 항상 O(nm)이다. 특히 n−m+1 = Θ(n)인 경우에는 Θ(nm)이다.
  • (c) 0번. KMP에서 텍스트 인덱스의 후진 횟수는 0회이다. 텍스트 인덱스는 후진하지 않으며, 패턴 인덱스의 증가 횟수와 실패 함수에 따른 감소 횟수가 각각 O(n)으로 제한되므로 검색은 O(n), 패턴 전처리 O(m)까지 포함한 전체 시간 복잡도는 O(n+m)이다.

한 줄 정리 · Naive는 시작 위치를 바꿀 때 이미 검사한 텍스트 구간을 다시 비교할 수 있어 최악 O(nm)이지만, KMP는 일치 정보를 재사용해 중복 비교를 제한하고 텍스트 인덱스를 후진시키지 않아 전체 O(n+m)에 수행된다.
