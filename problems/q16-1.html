Quiz 16-1

Greedy: at each vertex pick its locally cheapest outgoing edge. Does this work?

힌트 보기
개념 정리 · cut property
  • Cut property: 연결된 무방향 가중치 그래프에서 어떤 컷을 가로지르는 최소 가중치 간선 e는 적어도 하나의 MST에 포함된다. 그 컷에서 최소 간선이 유일하면 e는 모든 MST에 포함된다. 동점이 있을 때 각 간선이 개별적으로 안전하다는 사실만으로, 여러 간선을 동시에 선택한 결과까지 안전하다고 보장되지는 않는다.
  • 한 번 선택한 간선 집합이 반드시 연결된 트리가 되는지 확인하자. 각 정점의 선택 횟수와 서로 다른 무방향 간선의 실제 개수는 구분해야 한다.

정답 보기
풀이
  1. 한 번 적용의 결과. 각 정점이 하나의 최소 가중치 간선을 선택하더라도, 두 정점이 같은 무방향 간선을 선택할 수 있으므로 서로 다른 간선이 반드시 개인 것은 아니다.
    가중치가 모두 다를 때: 선택된 무방향 간선 집합에는 사이클이 생기지 않지만, 여러 컴포넌트로 분리될 수 있다. 이미 연결된 트리가 되는 경우도 있다.
    동점이 있을 때: 정점마다 동점 간선을 독립적으로 선택하면 길이 3 이상의 사이클도 생길 수 있다. 가중치가 모두 다르다면 선택된 간선으로 이루어진 임의의 사이클에서 가장 무거운 간선은 양 끝 정점 중 어느 쪽에서도 최소 간선으로 선택될 수 없으므로 모순이다. 그러나 사이클이 없다는 것만으로 연결성이 보장되지는 않는다. (반례) 연결된 경로 a−b−c−d에서 간선 가중치가 순서대로 1, 3, 2이면, 선택 결과는 {ab, cd}로 분리된다. MST는 모든 정점을 연결하고 사이클이 없으며, 간선이 정확히 개인 최소 가중치 신장 트리다. 따라서 정점별 선택을 한 번 수행하는 것만으로는 MST가 보장되지 않는다.
  2. 컴포넌트 단위 반복: Borůvka(Sollin) 알고리즘. 처음에는 각 정점을 하나의 컴포넌트로 둔다. 매 라운드마다 각 컴포넌트에서 다른 컴포넌트로 나가는 최소 가중치 간선을 찾고, 선택된 간선들로 컴포넌트를 병합한다. 연결된 입력 그래프에서 하나의 컴포넌트만 남으면 MST가 완성된다. 각 컴포넌트의 최소 outgoing edge는 해당 컴포넌트와 나머지 정점 사이의 컷을 가로지르는 최소 간선이므로 cut property에 따라 안전한 후보이다. 가중치가 모두 다르면 이 간선들을 동시에 선택해도 사이클이 생기지 않는다. 동점이 있으면 전역적으로 일관된 tie-break를 적용하거나 병합할 때 사이클을 검사해 포레스트를 유지한다. 매 라운드에서 중복 선택된 무방향 간선은 하나로 취급하며, 이미 같은 컴포넌트에 속한 두 정점을 연결하는 간선은 추가하지 않는다. 이렇게 안전한 간선들로 컴포넌트를 병합하는 과정을 반복하여 MST를 구한다.
  3. 동점 처리. 가중치가 같은 간선들이 있을 때 각 컴포넌트가 독립적으로 최소 간선을 선택하면, 선택된 무방향 간선 집합에 길이 3 이상의 사이클이 생길 수 있다. 예를 들어 세 간선의 가중치가 모두 1인 삼각형에서 a가 ab, b가 bc, c가 ca를 선택하면 세 간선이 모두 포함되어 사이클이 형성된다. 이를 방지하려면 모든 컴포넌트가 동일한 전역 순서, 예를 들어 (w(e), id(e))의 사전식 순서로 간선을 비교해 동점을 해소하거나, Union-Find로 병합 시 사이클이 되는 간선을 제외한다. 두 정점이 서로 같은 간선을 선택하는 것은 유향 선택 관계에서는 2-사이클로 표현될 수 있지만, 무방향 MST에서는 동일 간선의 중복 선택일 뿐이며 동점이 없어도 발생할 수 있다.
최종 답각 정점이 최소 가중치 간선을 한 번씩 선택하는 것만으로는 MST가 보장되지 않는다. 정점별 선택으로 얻은 컴포넌트에서 다시 최소 outgoing edge를 선택하고 병합하는 Borůvka 알고리즘을 반복하면 MST를 구할 수 있다. 가중치 동점이 있을 때는 일관된 tie-break 또는 사이클 검사가 필요하다
한 줄 정리 · 정점별 국소 최소 간선 선택 한 번으로는 MST가 보장되지 않으며, 컴포넌트 단위 선택과 안전한 병합을 반복하면 MST를 구할 수 있다.
