Mock Final Q7 (5점)

In the undirected weighted graph below all edge weights are distinct (so the MST is unique).

  1. Prove that edge AB (weight 1) belongs to every MST using the cut property (state the cut you use).
  2. Prove that edge AC (weight 4) belongs to no MST using the cycle property (state the cycle you use).
힌트 보기
개념 정리 · MST의 두 안전/제외 규칙
  • Cut property: 임의의 컷을 가로지르는 최소 가중치 간선은 적어도 하나의 MST에 포함된다. 그 간선이 컷을 가로지르는 유일한 최소 가중치 간선이면 모든 MST에 반드시 포함된다. 최소 가중치에 동률이 있으면 특정 최소 간선이 모든 MST에 포함된다고 보장할 수 없다.
  • Cycle property: 사이클의 유일한 최대 가중치 간선은 어떤 MST에도 속하지 않는다.

강의 슬라이드 Ch16 · Quiz 16-1, 16-3과 같은 개념

정답 보기
풀이
  • (1) 컷 ({A}, {B, C, D})를 잡는다. 이 컷을 가로지르는 간선은 AB = 1과 AC = 4뿐이고, AB = 1이 유일한 최소 가중치 간선이다. Cut property에 의해 AB는 모든 MST에 반드시 포함된다. 교환 논증으로도 확인할 수 있다. AB를 포함하지 않는 MST가 있다고 가정하면, A를 나머지 정점에 연결하기 위해 AC = 4를 반드시 포함해야 한다. 이 트리에서 AC = 4를 제거하고 AB = 1을 추가하면 연결성과 사이클이 없는 성질이 유지되면서 총 가중치가 3 감소한다(1 − 4 = −3). 이는 기존 트리가 최소 신장 트리라는 가정에 모순이므로 AB는 모든 MST에 포함된다.
  • (2) 사이클 A-B-C-A를 잡으면 간선은 AB = 1, BC = 2, AC = 4이다. 이 사이클에서 AC = 4가 유일한 최대 가중치 간선이므로 Cycle property에 의해 AC는 어떤 MST에도 속하지 않는다. 검산: MST = {AB, BC, CD}, 총 가중치 = 1 + 2 + 3 = 6. AC = 4는 사이클 A-B-C-A에서 유일한 최대 가중치 간선이므로 제외된다. BD = 5도 사이클 B-C-D-B에서 BC = 2, CD = 3, BD = 5 중 유일한 최대 가중치 간선이므로 Cycle property에 의해 제외된다.
최종 답(1) 컷 의 최소 간선 AB → 모든 MST에 포함   (2) 사이클 A-B-C-A의 최대 간선 AC → 어떤 MST에도 미포함
한 줄 정리 · 포함은 컷의 최소, 제외는 사이클의 최대로 증명한다.
